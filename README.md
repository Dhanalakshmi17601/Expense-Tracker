💰 Expense Tracker

A web-based Expense Tracker application developed using **PHP**, **MySQL**, **HTML**, **CSS**, **Bootstrap 5**, **JavaScript**, and **jQuery**. This application helps users efficiently manage their income, expenses, budgets, and financial reports through an intuitive dashboard.

📌 Features

- 🔐 User Authentication (Register, Login & Logout)
- 📊 Interactive Dashboard
- 💵 Add and Manage Income
- 💸 Add and Manage Expenses
- 📂 Category Management
- 🎯 Monthly Budget Management
- 📈 Financial Reports & Charts
- ⚙️ User Settings
- 📱 Responsive Design

🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Expense-Tracker.git
```

2. Move Project to XAMPP

Copy the project folder into:

```
xampp/htdocs/
```

3. Start XAMPP

Start:
- Apache
- MySQL

4. Import Database

- Open **phpMyAdmin**
- Create a new database
- Import the SQL file

5. Update Database Configuration

Edit `db.php` with your database credentials.

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "expense_tracker";
```

6. Run the Application

Open your browser and visit:

```
http://localhost/Expense-Tracker/
```
